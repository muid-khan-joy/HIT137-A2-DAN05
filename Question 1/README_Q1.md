# Question 1 – Cipher Program

## Files

| File | Description |
|---|---|
| `cipher.py` | The program |
| `raw_text.txt` | Input text supplied with the assignment |
| `encrypted_text.txt` | Generated by the program |
| `decrypted_text.txt` | Generated by the program |

The two generated files in this repository were produced with **shift1 = 3** and **shift2 = 4**.

## How to run

```bash
python cipher.py
```

`cipher.py` and `raw_text.txt` must be in the same folder.

The program asks for two values:

```
Enter shift1: 3
Enter shift2: 4
```

Both must be non-negative whole numbers. Anything else is rejected and the
question is asked again.

## Expected output

```
HIT137 Assignment 2 - Question 1

Enter shift1: 3
Enter shift2: 4

Encrypted raw_text.txt -> encrypted_text.txt
Decrypted encrypted_text.txt -> decrypted_text.txt
Verification: SUCCESS - the two files are the same.
```
